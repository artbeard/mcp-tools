# План развития управления Microsoft Project

## Этап 1. Идентификация и диагностика

- Открытые планы и доступ к ним.
- Дерево задач с `UniqueID`, иерархией, ограничениями и связями.
- Ресурсы, назначения, календари, критические задачи и перегрузки.

## Этап 2. Предварительный просмотр

- Добавление и изменение задач, вех, длительности, дат и связей.
- Явный выбор: изменить начало, окончание, длительность или ограничение.
- Предварительный просмотр ресурсов и назначений.

## Этап 3. Подтверждённое применение

- Проверка, что план не изменился после предварительного просмотра.
- Одна резервная копия рядом с исходным файлом перед первой записью в план за сессию.
- Применение, пересчёт, проверка инвариантов и сохранение.

## Этап 4. Расширенное управление

Реализован перенос несводной задачи к другому родителю:
`{"kind":"task","operation":"reparent","task_unique_id":45,"parent_unique_id":6}`.
Задача вставляется первой дочерней строкой; параметры задачи сохраняются. Microsoft Project
может назначить новый внутренний UniqueID при вставке вырезанной строки. Результат возвращает
предыдущий `previous_task_unique_id` и текущий `task_unique_id`; последующие команды используют
текущий идентификатор. Код задачи в названии не меняется.
Предварительный просмотр показывает целевого родителя. Перед сохранением проверяются
родитель, количество задач и набор UniqueID с единственной допустимой заменой переносимой
строки. При ошибке выполняется попытка отмены объединённой операции; если Project отвергает
отмену, возвращается ошибка, план не сохраняется. Перенос сводной задачи с её поддеревом,
задачи со связями или назначениями ресурсов пока запрещён. Перенос не назначает новые даты;
сводные даты старого и нового родителя пересчитываются Microsoft Project.

Для операции открывается таблица диаграммы Ганта, снимается фильтр и раскрывается дерево задач.
Свойства COM-выделения читаются через явный вызов свойства, чтобы PowerShell не перечислял
COM-коллекцию вместо её сохранения. Сценарий передаётся PowerShell через стандартный ввод
в UTF-8, чтобы не превышать ограничение длины командной строки Windows при запуске из WSL.

- Ресурсы, ставки, доступность, календари и трудозатраты.
- Перегрузки, критический путь, базовые планы и отчёты.
- Отдельные подтверждения для удаления и массовых операций.
