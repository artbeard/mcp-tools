# Модульная архитектура

Каждый модуль представляет собой описание небольшой части (раздела) предметной области

## Структура
```
src/
├── Controller/     # Общие контроллеры
├── Entity/         # Все Doctrine-сущности (общие)
├── Repository/     # Все репозитории (общие)
├── Service/        # Общие сервисы
├── Dto/            # Общие DTO
├── Enum/           # Общие перечисления
├── Modules/        # Модули фич
│   └── ModuleName/
│       ├── Controller/
│       ├── Service/
│       └── Dto/
└── Abstract/       # Базовые классы, трейты, интерфейсы
```

## Правила
- **MUST**: Каждый модуль изолирован в `src/Modules/{ModuleName}/`
- **MUST**: Модуль содержит только Controller, Service, Dto (и связанное)
- **MUST**: Сущности и репозитории остаются в корневых `src/Entity/` и `src/Repository/`
- **SHOULD**: Общая логика в корневых `src/Service/` или `src/Controller/`
- **SHOULD**: DTO модуля в `src/Modules/{ModuleName}/Dto/`
- **MAY**: Межмодульная коммуникация через общие сервисы или Symfony-события

## Когда создавать модуль
- Фича имеет 2+ контроллеров и выделенные сервисы
- Фича логически изолирована от других
- Фича может быть отключена/удалена независимо

## Именование
- Папка модуля: PascalCase (`Fbo`, `Goods`, `Orders`)
- Внутренняя структура зеркалит корневую
