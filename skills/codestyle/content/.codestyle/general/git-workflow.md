## Ветки
- **MUST**: Фича-ветки от `master`
- **SHOULD**: Именование веток: `feature/TASK-123-short-description`, `fix/TASK-123-description`; если номера задачи нет — `feature/short-description`

## Merge Request-ы
- **MUST**: Запустить `npm run dev:lint` перед созданием MR (фронтенд)
- **MUST**: Просмотреть сгенерированный SQL миграции перед мержем
- **MUST NOT**: Мержить без код-ревью
- **SHOULD**: Маленькие, сфокусированные MR вместо больших массовых изменений

## Коммиты
- **SHOULD**: Осмысленные сообщения коммитов — что и зачем
- **MUST NOT**: Коммитить закомментированный код (кроме временного дебага с TODO)
- **MUST NOT**: Коммитить `.env` файлы с секретами

## Ревью миграций
- **MUST**: После `make:migration` просмотри сгенерированный SQL и убери лишние операции
- **MUST**: Убедись, что имена таблиц/колонок корректны
- **MUST**: Проверь, что миграция не удаляет важные данные
- **MUST NOT**: Запускать миграцию без проверки её кода
- **SHOULD**: Тестировать миграции на стейджинге перед продакшеном

## Комментарии
- **SHOULD**: Комментарии предпочтительно на русском языке
- **MUST**: Удалять мёртвый/закомментированный код перед коммитом
- **MAY**: TODO-комментарии с описанием задачи допускаются
