# Правила форматирования

## Отступы
- **MUST**: Только **табы** (пробелы для отступов запрещены)
- **MUST**: Ширина таба: **4 пробела** для PHP, JS, TS, SCSS, Vue `<script>`
- **MUST**: Ширина таба: **3 пробела** для HTML, Twig, Vue `<template>`
- Примечание: В `.vue` файлах `<template>` использует табы по 3sp, `<script>` и `<style>` — по 4sp

## Переводы строк
- **MUST**: Unix-переводы строк (LF, `\n`)
- **MUST**: Кодировка UTF-8 для всех файлов
- **MUST**: Финальный перевод строки в конце файла (кроме `.md`)
- **MUST NOT**: Пробелы в конце строк (табы для выравнивания допускаются)

## Пустые строки
- **MUST**: Максимум **2 подряд** пустые строки
- **SHOULD**: Пустые строки между логическими блоками кода

## Скобки — Allman-стиль
Проект использует **Allman-стиль**: открывающая `{` всегда на новой строке.
Это отличается от стандарта PSR-12. ESLint контролирует: `'brace-style': ['error', 'allman']`.

- **MUST**: `{` на **новой строке** для `if`, `else`, `for`, `while`, `foreach`, функций, методов, классов
- **MUST**: Исключение — стрелочные функции: `{` на **той же строке** после `=>`
- **MUST**: Скобки обязательны для всех блоков (нельзя if без скобок в одну строку)

## Точки с запятой
- **MUST**: Точка с запятой обязательна после каждого выражения
- **MUST NOT**: Пробел перед точкой с запятой; пробел только после
- **MUST NOT**: Лишние/дублирующие точки с запятой

## Кавычки
- **MUST**: Одинарные кавычки (`'`) для строк
- **MAY**: Шаблонные литералы при необходимости интерполяции
- **MAY**: Экранированные кавычки внутри строк

## Пробелы в объектах
- **MUST**: Пробелы внутри фигурных скобок объектов: `{ key: value }`
- **MUST**: Пробелы вокруг операторов и после запятых

## Пример
```php
// PHP — Allman-скобки, табы
if ($user === null)
{
	return $this->json(['message' => 'Not found'], Response::HTTP_NOT_FOUND);
}

public function getProfile(User $user): array
{
	return ['id' => $user->getId()];
}

foreach ($items as $item)
{
	$this->process($item);
}
```

```typescript
// TypeScript — те же Allman-скобки
if (condition)
{
	doSomething();
}

function loadData(): Promise<Data>
{
	return api.getData();
}

// Стрелочная функция — исключение: скобка на той же строке
const handler = (item: Item) => {
	return process(item);
};
```

## Антипаттерн
```
// НЕПРАВИЛЬНО: K&R / PSR-12 скобки (не используются в проекте)
if (x) {
  return true;
}

// НЕПРАВИЛЬНО: пробелы для отступов
if (x)
{
  return true;  // 2 пробела вместо таба
}

// НЕПРАВИЛЬНО: if без скобок в одну строку
if (x) return true;  // Всегда используй скобки
```
