# Полный поток данных Full-Stack

## Путь запроса (Пользователь → БД)
```
Клик пользователя → Событие компонента → Экшен стора → **API-слой** (доменная функция на **ky**; legacy — **axios**)
    → HTTP → Контроллер → Сервис → Репозиторий → Сущность → MySQL
```

## Путь ответа (БД → Пользователь)
```
MySQL → Сущность → DTO (fromEntity) → Контроллер json() + HTTP-код
    → ответ HTTP-клиента → обновление стейта стора → перерисовка компонента
```

## Правила по слоям

### 1. Компонент → Стор
- **MUST**: Компонент вызывает экшен стора напрямую (не через цепочку emit родителю)
- **MUST NOT**: Компонент делает API-вызовы — всегда через стор
- **MUST**: Экшен стора возвращает Promise; компонент await-ит его

```vue
<script setup lang="ts">
const store = useProductStore();

async function handleCreate()
{
	try
	{
		await store.createItem(formData.value);
		// Успех: UI обновляется реактивно через стейт стора
	}
	catch (err)
	{
		showErrorNotification('Ошибка создания');
	}
}
</script>
```

### 2. Стор → API-слой
- **MUST**: Вызывать **доменные** функции API-слоя (см. `../frontend/api-layer.md`), а не размножать сырой **axios** / **ky** по экшенам
- **MUST**: Централизованные URL из `endpoints.ts` или констант домена; параметры — `url.productUpdate.replace(':id', String(id))` и т.п.
- **SHOULD**: Для запросов от пользователя передавать флаг глобальной загрузки (**`showGlobalLoading`** на **ky** или **`AxiosAnimation`** в legacy **axios**) — см. `../frontend/api-layer.md`
- **MUST**: Успех по контракту — обычно любой **2xx**; если ветвление зависит от **201** / **204**, обрабатывать явно в экшене или в обёртке домена, а не требовать «строго 200» без причины

### 3. API → Контроллер
- **MUST**: Контроллер оборачивает ввод в DTO: `DtoCreate::fromArray($request->toArray())`
- **SHOULD**: Или использовать `#[MapRequestPayload]` для автоматического маппинга
- **MUST**: Возвращать `$this->json($data, Response::HTTP_*)` — без обёрточных свойств

### 4. Контроллер → Сервис
- **MUST**: Контроллер делегирует ВСЮ бизнес-логику Сервису
- **MUST NOT**: Бизнес-логика в теле Контроллера
- **MUST**: Сервис получает DTO на вход, возвращает DTO[] на выход

### 5. Сервис → Репозиторий/БД
- **MUST**: Сервис получает репозиторий из `EntityManager` (без прямого внедрения)
- **SHOULD**: QueryBuilder для простых запросов, нативный SQL для сложных агрегаций
- **SHOULD**: Возвращать DTO, не сырые Entity-объекты

### 6. Обновление состояния
```
Экшен стора обновляет state → Компонент детектит реактивное изменение → UI перерисовывается
```
- **MUST**: Мутации только через экшены стора
- **MUST NOT**: Прямая модификация стейта из компонентов
- **MUST**: Реактивные поля стора для **шаблона** — только через **`storeToRefs(store)`**; экшены — с объекта **`store`** (см. `../frontend/store.md`)

## Поток обработки ошибок
```
Ошибка API → отклонённый Promise (ky / axios) → экшен стора реджектит → catch в компоненте
```
- **401**: перехватчик в **API-слое** — `refreshJwt(force=true)` + **один** retry; иначе redirect на Passport login (docs auth проекта (SSO/JWT))
- **403/404/500**: экшен реджектит; компонент показывает уведомление
- Глобально: при ошибке запроса с флагом глобальной загрузки API-слой эмитит **`http:global-loading:off`** (см. `../frontend/api-layer.md`)

```vue
<!-- НЕПРАВИЛЬНО: компонент напрямую вызывает API -->
<script setup>
const data = await goodsApi.list(); // НЕПРАВИЛЬНО: минуя стор
</script>
```

```php
// НЕПРАВИЛЬНО: контроллер содержит бизнес-логику
public function create(Request $request): JsonResponse
{
	$conn = $this->em->getConnection();
	$conn->insert(...);  // Должно быть в Сервисе!
	return $this->json(...);
}
```
