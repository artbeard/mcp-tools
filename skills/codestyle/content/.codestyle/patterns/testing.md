# Стратегия тестирования

## Backend: PHPUnit
- **SHOULD**: Тестировать критичную бизнес-логику (планирование, расчёт себестоимости, финансы)
- **SHOULD**: Тестировать DTO `fromArray()` с отсутствующими полями (ожидай краш)
- **MAY**: Интеграционные тесты для сложных SQL-запросов
- Директория тестов: `tests/` (PSR-4: `App\Tests`)

## Frontend: Vitest
- **SHOULD**: Тестировать composables с чистой логикой
- **SHOULD**: Тестировать экшены сторов с замоканным **API-слоем** (доменные функции / обёртка над **ky** или **axios**)
- **MAY**: Тесты компонентов для критичных UI-флоу

## Тестирование перед мержем
- **MUST**: Запустить `npm run dev:lint` (фронтенд)
- **SHOULD**: Тестировать с флагом `--dry_run` для команд, модифицирующих данные
- **SHOULD**: Тестировать миграции на стейджинге перед продакшеном
- **SHOULD**: Ручное тестирование затронутого CRUD-флоу

## Тестирование команд
```bash
# Пробный запуск для предпросмотра
php bin/console app:process --dry_run

# Тест на конкретной сущности
php bin/console sebes:recalculate --product=123456
```
