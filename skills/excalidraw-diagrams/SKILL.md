# Схемы Excalidraw

Создавай `.excalidraw` через MCP tool `excalidraw_create`. Передавай JSON-спецификацию в `diagram`, путь нового файла — в `output`. Существующие файлы генератор не перезаписывает.

## Оформление

По умолчанию используются прямые линии, мягкая заливка и шрифт Helvetica (семейство 2). У узла можно указать `role`: `front` — синий, `backend` — зелёный, `mixed` — голубой, `external` — серый с пунктиром, `note` — светло-серый, `decision` — янтарный. Ромб автоматически получает цвет решения. Сохраняй выбранную пользователем палитру при дальнейших изменениях.

Допустимые `shape`: `rectangle`, `ellipse`, `diamond`. Для вертикального процесса задавай `layout.direction: "vertical"`. Координаты и размеры узлов (`x`, `y`, `width`, `height`) нужны, если автоматической раскладки недостаточно. Длинный текст разбивай на строки, предусматривай достаточно места для подписей на переходах.

## Привязки и ручное редактирование

Добавляй `connections` только для настоящих связей. Генератор создаёт стрелку, её `startBinding`/`endBinding` и обратные ссылки `boundElements` в обоих блоках. Текущий формат привязки: `elementId`, `mode: "orbit"`, `fixedPoint` — относительная точка соединения. Не смешивай его со старым форматом `focus`/`gap`.

Подпись перехода задавай через `connections[].label`. Это текст с `containerId`, равным идентификатору стрелки, и обратной ссылкой в `arrow.boundElements`. Не заменяй подпись отдельным текстом или группой. `label_position` от 0 до 1 задаёт положение вдоль длины стрелки; по умолчанию — 0.5. При изменении маршрута подпись следует за стрелкой. Не расставляй координаты подписей вручную вне маршрута.

Для выхода и входа на нужных сторонах блока используй `start_side` и `end_side`: `top`, `bottom`, `left`, `right`. `waypoints` — промежуточные точки в абсолютных координатах. Если все сегменты идут горизонтально или вертикально, генератор создаёт настоящую угловую стрелку (`elbowed`) и фиксирует внутренние сегменты. Она сохраняет маршрут при перемещении блоков. Для такого маршрута указывай обе стороны явно.

После изменений проверяй не только JSON: открой файл в Excalidraw, перемести блок и убедись, что оба конца связанных стрелок и их подписи остаются привязанными. Проверь также перемещение подписи вдоль стрелки, отсутствие перекрытий и сохранение после повторного открытия.

## Исправление существующей схемы

Сначала прочитай текущий файл и сохрани резервную копию. Сохраняй ручные изменения пользователя: идентификаторы, тексты, палитру, положение и размеры блоков. Не генерируй схему заново поверх его правок.

`scripts/repair_scene.py --input old.excalidraw --output repaired.excalidraw` исправляет привязки и размещает подписи на стрелках. Скрипт создаёт новый файл, сохраняет удалённые элементы в истории, учитывает только действующие элементы при построении обратных ссылок. Схемы с повёрнутыми стрелками или блоками следует исправлять в редакторе. Проверь результат в редакторе перед заменой рабочего файла. При обновлении SVG экспортируй только действующие элементы; удалённые элементы не должны появляться в изображении.

## Пример

```json
{
  "layout": {"direction": "vertical", "gap": 100},
  "nodes": [
    {"id": "client", "label": "Фронт\nВвести ИНН", "role": "front"},
    {"id": "api", "label": "Бэк\nНайти организацию", "role": "backend"}
  ],
  "connections": [
    {"from": "client", "to": "api", "label": "Поиск", "start_side": "bottom", "end_side": "top"}
  ]
}
```
