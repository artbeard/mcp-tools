# Excalidraw Diagrams

Создавай `.excalidraw` через MCP tool `excalidraw_create`. Он принимает JSON-спецификацию в `diagram`, детерминированно строит объекты и сохраняет новый файл в `output`.

Используй узлы для сущностей, компонентов, шагов или решений. Допустимые `shape`: `rectangle` (по умолчанию), `ellipse`, `diamond`. Если координаты не заданы, порядок `nodes` определяет раскладку: `horizontal` по умолчанию или `vertical` в `layout.direction`.

Добавляй запись в `connections` **только когда на схеме действительно задумана связь или поток**. Для каждой такой записи генератор создаёт стрелку со `startBinding` и `endBinding`, а также регистрирует её у обоих объектов: при их перемещении в Excalidraw стрелка остаётся привязанной. Если у связи есть `label`, он создаётся как bound text стрелки и перемещается вместе с ней. Если связи нет, не создавай фиктивную стрелку.

Не перезаписывай существующий `output`: генератор намеренно откажется это делать. Сначала согласуй с пользователем смысл схемы, если он неоднозначен.

Минимальная спецификация:

```json
{
  "layout": {"direction": "horizontal", "gap": 100},
  "nodes": [
    {"id": "client", "label": "Клиент"},
    {"id": "api", "label": "API", "shape": "rectangle"}
  ],
  "connections": [
    {"from": "client", "to": "api", "label": "HTTPS"}
  ]
}
```

Задавай `x`, `y`, `width`, `height` у узла только когда автоматическая раскладка не отражает требуемую группировку. Читаемые подписи и короткие имена `id` предпочтительнее ручного редактирования JSON Excalidraw.
