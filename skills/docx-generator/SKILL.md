# DOCX Generator

Создавай DOCX через `bin/docx-create` (сборка: `make build-docx-create`). Передавай текст в JSON-файле и сохраняй результат в явно названный путь.

Без `--template` инструмент применяет фиксированный профиль `word-2024-base`: Aptos 11 pt, A4, поля 2,54 см, стили Normal, Title и Heading 1–3. Это воспроизводимый профиль, а не ссылка на пользовательский `Normal.dotm`: реальные настройки Word зависят от языка, региона и установки пользователя.

Если пользователь говорит «как в этом документе», передай его путь через `--template`. Инструмент сохраняет тему, таблицу стилей и параметры раздела образца (включая размер страницы, поля и колонтитулы); у новых абзацев применяется его стиль по умолчанию. Для точного применения специального стиля задай его идентификатор в поле `style` нужного абзаца.

Пример входного JSON:

```json
{
  "title": "Отчёт",
  "paragraphs": [
    {"text": "Вводный текст."},
    {"text": "Раздел", "style": "Heading1"}
  ]
}
```

Сначала создай файл JSON, затем запусти `bin/docx-create --input <json> --output <docx> [--template <образец.docx>]`. Не перезаписывай существующий результат или образец без явного разрешения пользователя.
